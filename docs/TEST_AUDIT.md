# AUV 测试体系审计

审计日期：2026-10-28，北京时间。范围仅为当前 AUV 工作区，包括尚未提交的规划和行动检查优化；不对 Promethea 作覆盖声明。

## 改造前基线

本轮先运行完整后端：413 passed，11.58s；最慢项为 OS 租约异常退出3.44s、24轮引擎1.81s。先前当前树前端基线为15文件/65项通过及生产构建通过。所有离线测试使用假模型，不花费供应商费用；这些数值不是智能行为准确率或覆盖率百分比。

主要缺口：关键词命中可以把明确遗忘判为100分；CLI成功只表示流程成功而不是质量通过；稀疏检查点手工注入记忆，不验证完整长程编码；普通模拟跨不同配置仍比较分数；没有自动CI和统一分层入口；API E2E替换队列，前端缺少浏览器全旅程；语义Judge尚无校准与误判统计。没有发现足以支持批量删除风险用例的证据。

## 核心能力覆盖矩阵

| 能力 | 确定性/模块集成证据 | 智能行为评测重点 | 系统证据与局限 |
| --- | --- | --- | --- |
| Planning | 模式DTO、截断恢复、原文、独立预算 | 目的/角色/终止条件，研究与角色扮演不串场 | 自然语言固定场景；未付费复测不报提升 |
| Actor/自主性 | 严格输出、本人所有权、外接一次执行 | 新贡献、角色范围、群体不是单人 | 连续引擎日志，不用intent自证自主性 |
| Action Check | 六类协议、引用、拒绝不传播、去重 | 时空冲突、可接受谎言、越权、秘密泄露、误拒绝 | 统计输入与误判，不能只看accept数量 |
| Director/推进 | Scene Contract、两类停滞、反馈、完整结束 | 新对白不等于目标收敛，微小进展、诚实停止 | 使用逐轮行动与审计，不以task_complete自证 |
| State Coder | 类型/私有归属、来源、游标、事务、恢复 | 持久相关性、断言/事实区分、忽略短暂描写 | 24轮假模型验证工程，不证明抽取质量 |
| 记忆/情景理解 | 可见性、激活、旧信息与预算 | 遗忘、纠错、指代、误解、私有知识 | sparse checkpoint仅受控召回，非自主60轮 |
| 信息隔离 | HTTP/模板/定向边/私有状态 | 自然语言泄密、凭空知情 | 标记词只能证明部分边界 |
| 任务收敛 | stop/上限不等于完成 | 是否真正到用户请求的终点 | 固定开场/结尾/研究场景，独立判定 |
| 报告/文学改写 | 来源完整、忠实度修订、拒绝不发布 | 源事实、体裁和风格分别评分 | 不让改写补造未模拟结局 |
| 生命周期 | 真实队列、SQLite、恢复、审计、回滚 | 不需要额外模型 | 新增真实服务生命周期系统冒烟 |
| 前端状态感知 | Zustand/API/轮询/广播/组件 | 通常不需要Judge | 未安装浏览器测试框架，视觉/拖拽仍需人工 |

## 评审边界

新增语义案例与标签由工程整理，不冒充已完成人工审查。正式Judge校准需要用户审阅标准案例并确认标签；未确认只能标为provisional，不自动认证模型质量。普通CI不得读取真实模型密钥发起付费请求。覆盖百分比、真实模型通过率、误判率或费用收益没有测量就记为未测，不用测试条数代替。

## 实施结果与前后对比（2026-10-29）

| 指标 | 改造前 | 改造后 |
| --- | --- | --- |
| 独立风险场景删除 | 不适用 | 0；4项scope参数只迁移归组 |
| 后端工程回归 | 413通过、未分层 | 471通过：314单元、154集成、3系统 |
| 前端 | 15文件/65通过、构建通过 | 保留65项并再次通过，构建通过 |
| 服务系统冒烟 | API流程使用捕获队列 | 新增真实生命周期/SQLite/Worker，覆盖停止、报告、人工恢复 |
| 模型职责评测 | 主要为整体场景、固定文风、手工记忆探针 | 8类职责/19项案例，可单独选择并重复运行 |
| Judge校准 | 无独立校准流程 | 17项待审标准；按职责复用、独立过期、混淆矩阵和误判统计 |
| 假通过 | 关键词命中可被视作召回质量；缺评审也退出成功 | 关键词只诊断；未校准/模糊/未执行不能成为质量通过 |
| 基线比较 | 普通模拟配置不一致仍显示升降 | 可比身份、重复次数与完整性检查；代码指纹另存，显式保存新版本 |
| 失败诊断 | 主要依赖规则分和最后审计 | case/trial/stage、物理调用区间、结束原因/指纹、编码游标与拒绝码 |
| 自动化与成本 | 人工选择命令 | 统一入口、进程超时、隔离数据、真实HTTP禁用、CI配置；新增依赖0 |

本轮后端基线11.58s，最终28.96s；增加了系统路径与评测器反例。此前470项曾为14.29s，OS进程和24轮引擎耗时随主机负载明显波动，不能据此判断产品性能变化。工程比较保存在 `backend/evals/baselines/offline_v1.json`，未安装覆盖率工具，不虚构覆盖百分比。

新增 `test_benchmark_contracts.py` 验证评分、校准、预算、基线和案例路由，`test_system_journey.py` 验证服务闭环，`conftest.py/pytest.ini` 管理隔离和分层，`scripts/verify.py` 与CI共用入口。旧宽松Judge解析函数删除，改用有依据引用及不确定分支的严格协议。执行方法见 [TESTING.md](TESTING.md)。

本轮真实模型调用0、费用0。模型准确率、误拒绝/漏检率、长程叙事和实际费用变化未测，需用户审阅校准标签并单独授权后建立真实基线。浏览器端到端与视觉自动化仍是明确盲区。
