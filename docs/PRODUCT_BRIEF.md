# AUV 产品概览

最后更新：2026-04-09

## 1. 产品定位

AUV 是一个本地单机可运行的可视化多 Agent 编排与模拟平台。

用户可通过拖拽式节点画布快速构建协作流程，并在运行时实时观察每个节点状态、事件、性能与结果。

## 2. 核心价值

1. 低门槛：可视化编排替代手写流程代码  
2. 可控：导演节点 + 人工干预机制保证流程可纠偏  
3. 可追溯：事件流、节点输入输出、运行历史完整可回放  
4. 可扩展：支持外接自定义 Agent（文本协议 v1.0）  
5. 可复用：模板系统支持一键复现成功配置  

## 3. 典型场景

1. 协作任务编排：Planner -> Coder -> Reviewer  
2. 调研模拟：多角色分析后汇总到综述节点  
3. 角色扮演：关系驱动互动（汇报/指令/反馈/交接）  
4. 人机共驾：流程中断后由人工输入决策再继续运行  

## 4. 当前能力边界

1. 当前主流程聚焦文本协作（多模态后续扩展）  
2. 单用户本地模式，无登录、多租户与云协作  
3. 执行策略默认串行，支持队列与并发 worker（run 级）  
4. 工具调用白名单控制，避免任意命令执行风险  

## 5. 自动与手动双模式

1. 自动模式：用户上传/粘贴计划文本，系统自动解析并生成可运行工作流
2. 手动模式：用户可在画布与参数面板中逐节点精细配置，并使用快捷角色按钮加速搭建
